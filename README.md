# Arquitectura UTMACH — Sitio informativo para aspirantes

Sitio web informativo independiente, elaborado a partir del material compartido sobre la malla curricular 2026 de Arquitectura de la Universidad Técnica de Machala.

## Publicar con GitHub Pages

1. En https://github.com/new crea un repositorio público, por ejemplo `arquitectura-utmach`.
2. En el repositorio, selecciona **Add file → Upload files** y sube `index.html` y `.nojekyll` desde este paquete (puedes subir también este README).
3. Confirma los archivos con **Commit changes** en la rama `main`.
4. Abre **Settings → Pages**. En **Build and deployment**, escoge **Deploy from a branch**; elige rama **main** y carpeta **/(root)**. Pulsa **Save**.
5. Cuando GitHub indique que el sitio está publicado, su dirección será `https://TU-USUARIO.github.io/arquitectura-utmach/`, reemplazando `TU-USUARIO` por tu usuario y ajustando el nombre del repositorio si es distinto.
6. Abre ese enlace en un teléfono antes de crear/imprimir el QR. Genera el QR a partir de la URL pública exacta.

**Importante:** No compartas la dirección de ejemplo como si fuera un enlace real. La publicación depende de los ajustes de tu cuenta y repositorio.

## Estructura

- `index.html`: sitio completo en un solo archivo con estilos y JavaScript incluidos.
- `.nojekyll`: permite servir los archivos directamente, sin procesamiento Jekyll.
- `README.md`: estas instrucciones.

## Contenido

Presentación de la carrera, información académica, perfil de egreso, malla curricular interactiva y orientación para futuros aspirantes. No incluye entrevistas ni la sección de documentos compartidos.

Este es un material de divulgación, no una página oficial de admisiones. Para fechas y requisitos vigentes, consultar https://www.utmachala.edu.ec/.
